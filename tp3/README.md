# TP 3 — Statistiques d'une série de notes (correction)

Compilation (GCC 14+ ou Clang 18+ requis pour <print>) :

    g++ -std=c++23 -Wall -Wextra -Wpedantic -Wconversion -Wshadow src/main.cpp -o tp3
    ./tp3 < exemple_entree.txt

Ou avec CMake :

    cmake -B build && cmake --build build && ./build/tp3

MSVC : option /utf-8 (déjà dans le CMakeLists.txt).
